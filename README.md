# 🍽️ Random Meal Generator

## 📌 Project Overview

Random Meal Generator is a simple and user-friendly web application that helps users discover random meal ideas. With just one click, users can generate a random meal and explore its recipe details, ingredients, food image, and cooking instructions.

The application uses TheMealDB API to retrieve meal information dynamically.

## ✨ Features

- Generate random meals with one click.
- Display meal names and images.
- Show meal categories and country of origin.
- Display ingredients and their measurements.
- Provide detailed cooking instructions.
- Show YouTube recipe videos when available.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- TheMealDB API

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.

## 🌐 API Used

[TheMealDB API](https://www.themealdb.com/api.php)

The application uses the random meal endpoint to fetch meal information.
